# AI Usage

AI tools were used during the development of this project as
development assistance.

## How AI Was Used

AI assistance was used for:

- Understanding the concepts involved in building a RAG-based
  document question-answering system.
- Planning the project structure and development steps.
- Getting help with Python code and debugging errors.
- Understanding package and dependency compatibility issues.
- Improving the Streamlit user interface.
- Reviewing and improving project documentation.

## AI-Assisted Development

The development process was performed incrementally.

The main pipeline was implemented and tested step by step:

1. PDF text extraction
2. Text chunking
3. Embedding generation
4. Semantic retrieval
5. LLM-based answer generation
6. Source attribution
7. Streamlit interface
8. PDF upload functionality
9. Performance improvements
10. Documentation

AI suggestions were tested locally and modified when necessary
to work with the project's Python environment and hardware.

## Human Understanding and Verification

The project was not treated as a black-box AI-generated solution.

Each major component was tested independently and its behavior
was verified using actual questions against the document.

The retrieval system was tested with both answerable and
unanswerable questions.

Two chunking configurations were also tested and compared before
selecting the final configuration.

The final implementation and design decisions were reviewed and
understood during development.
